POINT CAFE — نسخة التطبيق المطابقة للمتجر

نقطة الدخول للتطبيق: index.html
Manifest: store-manifest.json
الوضع: standalone

مهم: التطبيق يفتح نفس صفحة المتجر نفسها (index.html) بدون تصميم أو ترتيب بديل.
يتم استخدام نفس الألوان والخطوط والمكونات والمنتجات الموجودة في صفحة المتجر.
ملفات Firebase الخارجية تبقى عبر الشبكة حتى تعمل بيانات المتجر والطلبات بشكل طبيعي.
