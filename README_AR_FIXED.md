# POINT CAFE — نسخة الإصلاح

تم إصلاح/إضافة الآتي:
1. منع تعيين السائق تلقائياً عند إنشاء الطلب؛ الطلب يبقى «جديد» حتى يختار المدير السائق.
2. عند اختيار السائق من لوحة المدير يتم إرسال الطلب له فوراً وتظهر الحالة «تم إرسال الطلب للسائق».
3. إضافة إلغاء الطلب من المدير مع سبب واضح:
   - الحوالة غير صحيحة
   - مشكلة في الطلب
   - سبب يكتبه المدير
   ويظهر السبب للعميل داخل «طلباتي».
4. إضافة صفحة `product.html` لعرض صورة المنتج بشكل كبير، السعر، المواصفات، وزر «إضافة إلى السلة»، مع «قد يعجبك أيضاً».
5. ربط سلة المنتج بمتجر `index.html` عبر `localStorage` مع إظهار عدد المنتجات في السلة.
6. إضافة قسم «قد يعجبك أيضاً» أسفل المنتجات في الصفحة الرئيسية.
7. تحسين مزامنة حالة تسجيل دخول العميل بعد نجاح Firebase Auth لتجنب رسالة الحالة القديمة قبل اكتمال الحالة.
8. إضافة ملفات manifest التي تشير إليها الصفحات الحالية.

## مهم جداً: سبب عدم حفظ المنتجات في السحابة
ملف `firestore.rules` الحالي في المشروع يحتوي على:
`ضع_UID_المدير_هنا`
ولذلك Firebase سيرفض كتابة المنتجات/الإعدادات حتى يتم وضع UID حساب المدير الحقيقي ثم نشر القواعد.

الخطوات:
- افتح `admin.html` وسجّل الدخول.
- انسخ «UID المدير الحالي» الظاهر في قسم النسخ الاحتياطي.
- افتح `firestore.rules`.
- استبدل `ضع_UID_المدير_هنا` بالـ UID الحقيقي.
- Firebase Console → Firestore Database → Rules → Publish.

لا أنصح بفتح الكتابة لجميع المستخدمين كحل بديل، لأن ذلك يسمح لأي حساب عميل بتعديل المنتجات والإعدادات.

## ملاحظة
`driver-stats.html` لم يتم تضمينه في النسخة النهائية حسب طلب حذف ملف الإحصائيات فقط.

10. إضافة تقييم خاص لكل منتج داخل صفحة `product.html` مع متوسط التقييم وعدد التقييمات.
11. إضافة متوسط تقييم المنتج إلى بطاقات المنتجات في المتجر.
12. تغيير اللغة أصبح يغير النصوص فقط؛ اتجاه الصفحة ومواقع الشعار والأيقونات والأقسام ثابتة ولا تنقلب.
13. تحسين حذف حساب العميل: السماح للعميل بحذف طلباته الخاصة وفق قواعد Firestore، مع إعادة المصادقة عند الحاجة قبل الحذف النهائي.
