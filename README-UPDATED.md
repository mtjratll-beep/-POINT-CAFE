# POINT CAFE — الإصدار الموحد

- حفظ جلسة تسجيل الدخول عبر Firebase على الجهاز.
- إذا كان المستخدم مسجلًا بالفعل تختفي شاشة تسجيل الدخول وتظهر الحساب مباشرة.
- Google: نجاح المصادقة لا يُعامل كفشل بسبب مشكلة مزامنة Firestore.
- زر تسجيل الدخول يفتح الحساب مباشرة إذا كانت جلسة Firebase موجودة.
- طلباتي/تتبع الطلبات كامل الشاشة على الجوال.
- إصلاح عرض لوحة المدير على الجوال.
- تفضيل إشعارات البريد الإلكتروني موجود في الحساب.
